# Security

Please report a security problem privately, through
[GitHub's private vulnerability reporting](https://github.com/Roasbeef/pondline/security/advisories/new),
and not in a public issue.

Pondline is pre-1.0 and hasn't had an independent security review, and the wire
format and profile aren't frozen. Please weigh that before relying on it for
anything sensitive. The
[security model](README.md#security-model) says what it does and doesn't claim.
